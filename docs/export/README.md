# Sơ đồ xuất PNG

Các file PNG trong thư mục này là ảnh xem nhanh nội dung thiết kế hiện tại. File nguồn có thể chỉnh sửa nằm ở `docs/*.drawio`.

Khi chuẩn bị PDF nộp chính thức, hãy mở từng file `.drawio` bằng diagrams.net/Draw.io và xuất lại PNG từ chính file nguồn để bảo đảm bố cục và nội dung khớp hoàn toàn.
